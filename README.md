# RoboDog
An IoT-based  robotic dog built with ESP32, featuring a 3D-printed structure, servo motors, and Arduino IDE programming. The project combines mechanical design, electronics, and embedded programming to create a functional robotic dog

## Components
- ESP32
- Servo Motors
- 3D Printed Body and Legs
- Electronic Components 

## Software 
- Arduino IDE
- SolidWorks 

## How It Work
The ESP32 acts as the main controller, receiving inputs and controlling the servo motors. The motors are programmed through Arduino IDE to coordinate the movement of the four legs and produce the desired robotic motion.
